# Workflow
1. Doctor registers patient -> case-taking (AYUSH fields, missing-info prompts).
2. Report upload (PDF/JPG/PNG) -> stored under a random name -> AI service extracts values.
3. Rules compute flags + traffic-light levels; low-confidence rows marked for review.
4. Practitioner reviews/edits values -> flags recomputed -> confirms.
5. Plain-language summary + curated guidance in en/hi/mr.
6. Trends: previous-vs-current comparison and charts across reports.
