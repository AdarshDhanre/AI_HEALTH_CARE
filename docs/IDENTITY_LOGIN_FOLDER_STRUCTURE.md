# Identity login feature folders

The project now has three peer folders:
- `ayushman_login_system/` — existing Ayushman Bharat card scanner
- `aadhaar_login_system/` — Aadhaar reference feature and privacy notes
- `mobile_email_login_system/` — mobile/email OTP feature and delivery setup

The active UI and API code remains in the existing `frontend/` and `backend-java/` folders to avoid duplicating application code or breaking current imports. See each feature folder's README for the exact active source paths.
